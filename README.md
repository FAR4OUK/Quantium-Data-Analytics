
# Quantium Retail Analytics - Data Analytics Virtual Internship

This project was completed as part of the **Quantium Data Analytics Virtual Internship. It simulates a real-world retail analytics engagement, using transaction data to generate commercial insights and evaluate trial store performance for a category manager.

## 📋 Project Overview

The internship is split into two main tasks:

### Task 1: Data Preparation and Customer Analytics
- Cleaned and merged transaction and customer datasets
- Performed exploratory data analysis (EDA) on chip category sales
- Segmented customers by **life stage** and **premium/mainstream/budget** classification
- Identified purchasing behaviour trends across customer segments to support category strategy recommendations

### Task 2: Experimentation and Uplift Testing
- Selected control stores comparable to trial stores using correlation and magnitude-distance metrics
- Assessed the impact of a store trial on sales performance
- Compared trial vs. control store metrics (total sales, customer numbers, transactions per customer) over the trial period
- Drew conclusions on whether the trial layout/strategy drove measurable uplift

## 🛠️ Tech Stack

- **Python** (pandas, numpy, matplotlib/seaborn) — data cleaning, EDA, visualization
- **Jupyter Notebook** — analysis walkthroughs

## 📊 Key Findings

Developed a store-matching methodology by analyzing historical sales and customer data, using correlation, scaling, and statistical validation to identify the most suitable control stores for retail trial evaluation.
Measured trial performance by comparing test and control stores, calculating percentage differences and statistical significance (t-values) to quantify the impact of the retail intervention on sales and customer metrics.
